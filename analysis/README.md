# Analysis posts
Har post ek `.md` file hai is folder mein. Naya post: GitHub par is folder mein "Add file" > "Create new file", naam `2026-11-12-nifty-overview.md`, `_template.md` ka text paste karke likhein, "Commit changes". 1-2 minute mein site par aa jayega.
- `draft: true` likhne se post chhupa rehta hai. Future `date` wala post us din ke baad dikhta hai (site roz subah rebuild hoti hai).
- `category` sirf: DAILY_OVERVIEW, NIFTY_ANALYSIS, BANKNIFTY_ANALYSIS, GOLD, SILVER, CRYPTO, EDUCATION, ECONOMIC_NEWS, TECHNICAL_ANALYSIS.
- Images `analysis/images/` mein daalein aur `image: images/naam.jpg` likhein.
- Buy/sell calls, target, stop-loss, guarantee jaise shabd likhne par site build ruk jati hai (compliance check). Kuch bhi publish karne se pehle SEBI rules dekhein.
- Is mode mein paid/premium-only posts nahi ho sakte (sab public hai).
